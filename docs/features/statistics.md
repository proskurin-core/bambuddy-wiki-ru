# Панель статистики {#statistics-dashboard}

Страница статистики предоставляет аналитику с помощью настраиваемых виджетов, которые можно перетаскивать.

![Страница статистики](../assets/statistics.png){ .screenshot }

---

## :material-view-dashboard: Обзор панели {#dashboard-overview}

Панель содержит несколько виджетов, которые можно:

- **Перетаскивать**, меняя их порядок
- **Изменять в размере**, выделяя важные данные
- **Скрывать**, если они не нужны
- **Сбросить** к первоначальному расположению

## :material-chart-pie: Доступные виджеты {#available-widgets}

### Доля успешных печатей {#print-success-rate}

Отслеживайте надёжность всех принтеров:

| Статус | Описание |
|:------:|-------------|
| :material-check-circle:{ style="color: #4caf50" } Успешно | Завершённые печати |

- Наглядная круговая диаграмма
- Фильтрация по принтеру
- Процент успешных печатей

### Расход филамента {#filament-usage}

Отслеживайте расход материалов:

- **По типу** — PLA, PETG, ABS и т. д.
- **По цвету** — распределение цветов
- **За период** — графики изменения
- **Общий вес** — суммарные кг/г
- **Энергия за период** — если печати за выбранный период содержат данные об энергии, измеренной умной розеткой, дополнительный график показывает кВт·ч по дням (по часам для периодов не длиннее недели). В заголовке приведены суммарное потребление и стоимость энергии за период. Без [умной розетки](smart-plugs.md) график не отображается.

!!! info "В рекордах учитываются затраты на энергию и износ"
    Рекорд **Самая дорогая** ранжирует печати по стоимости филамента **плюс** измеренная стоимость энергии для каждой печати **плюс** [износ принтера](#printer-wear-cost). Если какая-либо стоимость для печати не записана, она не прибавляется.

### Календарь активности печати {#print-activity-calendar}

Календарь активности в стиле GitHub:

- Тепловая карта ежедневной активности
- Интенсивность цвета соответствует количеству печатей
- Нажмите на день, чтобы увидеть печати
- Выявляйте закономерности печати

### Краткая статистика {#quick-stats}

Сводные показатели:

- **Всего печатей** за выбранный период
- **Всего филамента** израсходовано (в граммах)
- **Стоимость филамента**
- **Общее время печати**
- **Расход / стоимость энергии** — с учётом режима в разделе Настройки → Общие → Энергия (по печатям или общее потребление) и выбранного периода.
- **Стоимость износа** — износ принтеров за период (см. [Стоимость износа принтера](#printer-wear-cost)). Показатель появляется после задания стоимости износа хотя бы одного принтера.

!!! note "Требуется настройка"
    Для расчёта стоимости необходимо указать цены филамента в настройках.

!!! info "Статистика суммируется по событиям печати, а не по файлам архива"
    Краткая статистика и запросы статистики суммируют отдельные события печати — те же данные, что лежат в основе [журнала печати архива](archiving.md#per-archive-print-log), — а не строки архива. Поэтому каждая повторная печать вносит собственный расход филамента, время, стоимость и количество в итоги, даже если один архивный 3MF печатался десять раз. Неудачная повторная печать с расходом 10 г и предыдущая успешная печать на 100 г записываются как два отдельных события; краткая статистика правильно суммирует 110 г, а не перезаписывает данные исходного архива неудачной попыткой.

!!! info "Удаление архива сохраняет его вклад в краткую статистику"
    По умолчанию удаление записи со страницы архива **не вычитает** её расход филамента, время, стоимость или энергию из краткой статистики: файл удаляется с диска, строка исчезает из списков, но итоги сохраняются. Чтобы исключить печать из статистики, установите флажок **Также удалить эту печать из краткой статистики** в диалоге подтверждения. Подробнее см. [Поведение при удалении](archiving.md#delete-behavior). При таком полном удалении также удаляются связанные записи журнала печати, и вклад каждого запуска исчезает из итогов.

!!! tip "Индикатор накопления данных об энергии"
    В режиме **Общее потребление** значения энергии за период вычисляются по часовым снимкам общего счётчика каждой умной розетки. После новой установки или вскоре после обновления снимка до начала выбранного периода может ещё не быть: на плитках расхода и стоимости энергии появляется жёлтый значок с поясняющей подсказкой. Примерно через час работы индикатор исчезает для периодов, начинающихся после первого снимка. Подробнее см. [Учёт энергии](energy.md#total-mode).

### Точность времени {#time-accuracy}

Сравнивайте расчётное и фактическое время печати:

- **Средняя точность** — насколько близки оценки
- **По принтеру** — сравнение точности принтеров
- **Динамика** — улучшается ли точность?

Каждая печать сравнивается с оценкой слайсера для напечатанной пластины, поэтому печать одной пластины многопластинного файла считается одной пластиной, а не всем файлом. Оценки более чем вдвое выше или ниже фактического времени исключаются как выбросы, например если вы вмешались в печать.

### Распределение длительности печати {#print-duration-distribution}

Определяйте типичную длительность:

- Столбчатая диаграмма с диапазонами длительности (<30 мин, 30 мин–1 ч, 1–2 ч, 2–4 ч, 4–8 ч, 8–12 ч, 12–24 ч, более 24 ч)
- Быстрый обзор наиболее частого диапазона

### Филамент по типу {#filament-by-type}

Круговая диаграмма распределения материалов:

- Нажимайте на сегменты для фильтрации
- Легенда с точными количествами
- Процентное распределение

### По поставщику {#by-supplier}

Расход и стоимость сгруппированы по месту покупки катушек:

- Одна строка на поставщика, отмеченного как **Куплено здесь** хотя бы у одной катушки (см. [Поставщики](inventory.md#suppliers))
- **Катушки** и **Остаток** — всегда текущее состояние; перерасходованная катушка считается пустой
- **Израсходовано** и **Стоимость** — по записанной истории расхода за выбранный период, включая архивные катушки
- Сортировка по расходу от большего к меньшему
- Виджет скрыт в режиме Spoolman: он группирует собственные катушки Bambuddy, а не назначения для катушек Spoolman

### По номеру материала {#by-material-number}

Запасы, расход и стоимость сгруппированы по внутреннему номеру материала (см. [Номера материалов](inventory.md#material-numbers)):

- Одна строка на используемый номер материала; катушки без номера исключаются
- **Катушки** и **Остаток** — всегда текущее состояние; перерасходованная катушка считается пустой и не уменьшает остаток других катушек
- **Израсходовано** и **Стоимость** — по записанной истории расхода за выбранный период, включая архивные катушки. Номер с запасом, но без расхода за период также отображается с нулевым расходом
- Сортировка по расходу от большего к меньшему; при равном расходе — по номеру для стабильного порядка
- Виджет скрыт в режиме Spoolman: он группирует собственные катушки Bambuddy

## :material-gesture-tap-drag: Настройка расположения {#material-gesture-tap-drag-customizing-layout}

### Перетаскивание {#drag-and-drop}

Чтобы переставить виджеты:

1. Наведите курсор на заголовок виджета
2. Нажмите значок захвата :material-drag:
3. Перетащите виджет на новое место

Чтобы изменить размер виджета:

1. Нажмите значок изменения размера на виджете
2. Размеры переключаются по кругу: маленький → средний → большой → во всю ширину
3. Расположение изменится автоматически

### Скрытие виджетов {#hiding-widgets}

Чтобы убрать виджет с экрана:

1. Нажмите значок **глаза** :material-eye-off: на виджете
2. Виджет будет скрыт
3. Верните его через элементы управления

### Расположение элементов управления {#controls-location}

Элементы управления находятся в строке заголовка панели:

- **Скрытые** — показать скрытые виджеты и управлять ими

### Сохранение настроек {#persistence}

Настройки расположения:

- Сохраняются автоматически

## :material-filter: Фильтрация данных {#filtering-data}

### Период {#time-range}

| Период | Описание |
|-------|-------------|
| Сегодня | С полуночи |
| Эта неделя | С понедельника |
| Этот месяц | С первого числа |
| Последние 7 дней | За последнюю неделю |
| Последние 30 дней | За последний месяц |
| Последние 90 дней | За последний квартал |
| Этот год | С 1 января |
| Всё время | Все данные |
| Произвольный | Выберите даты начала и окончания |

Дни считаются календарными днями в часовом поясе браузера, а не UTC: в 01:30 «Сегодня» означает период с местной полуночи, даже если Bambuddy работает в другом часовом поясе.

### Фильтрация по пользователю {#per-user-filtering}

Фильтруйте всю статистику по конкретному пользователю. Это полезно в университетах, мастерских и многопользовательских установках для учёта действий и затрат по каждому человеку.

**Требования:**

- Должна быть включена аутентификация
- У пользователя должно быть разрешение `stats:filter_by_user` (по умолчанию только у администраторов)

**Использование:**

1. Нажмите **список пользователей** в заголовке статистики рядом с выбором периода
2. Выберите пользователя, чтобы видеть только его печати, расход филамента и затраты
3. Выберите **«Все пользователи»**, чтобы вернуться к общей статистике
4. Выберите **«Без пользователя (система)»**, чтобы увидеть печати без привязки к пользователю, например запущенные слайсером или до включения аутентификации

Фильтр применяется ко всем виджетам, анализу неудач и экспорту CSV/Excel.

!!! info "Пользовательские группы разрешений"
    Чтобы предоставить это разрешение не администраторам, создайте группу в **Настройки → Пользователи** и добавьте разрешение `stats:filter_by_user`.

### Выбор принтера {#printer-selection}

Просматривайте статистику:

- По **всем принтерам** вместе
- Только по **отдельному принтеру**
- В режиме **сравнения** принтеров

## :material-cash: Настройка стоимости {#cost-configuration}

Чтобы включить учёт затрат:

1. Перейдите в **Настройки** > **Филаменты**
2. Добавьте филаменты:
   - Тип материала
   - Цвет
   - **Стоимость за кг**
   - Поставщика (необязательно)
3. Статистика рассчитает затраты автоматически

### Расчёт стоимости {#cost-calculation}

```
Print Cost = (Filament Used in grams / 1000) × Cost per kg
```

Для печатей на принтере с назначенной [умной розеткой](smart-plugs.md) дополнительно записывается измеренная **стоимость энергии** (см. [Учёт энергии](energy.md#cost-calculation)). Эти данные используются в плитках расхода и стоимости энергии, графике энергии за период и рекорде самой дорогой печати; в остальном стоимость филамента и энергии показывается отдельно.

### Стоимость износа принтера {#printer-wear-cost}

При печати изнашиваются сопла, ремни, хотэнд и со временем сам принтер. Чтобы учесть это в стоимости, задайте каждому принтеру **стоимость износа за час печати**:

1. На странице **Принтеры** откройте меню принтера и выберите **Изменить**
2. Введите **стоимость износа за час печати**, например `0.20` для принтера стоимостью 600 с предполагаемым ресурсом 3 000 часов
3. Сохраните изменения

```
Wear Cost = Print duration in hours × Wear cost per printing hour
```

- Используется длительность запуска из [журнала печати](print-log.md), включая неудачные и отменённые запуски, которые тоже изнашивают принтер. Для запуска, закрытого после отключения Bambuddy, длительность неизвестна и стоимость износа не начисляется.
- Ставка применяется со следующей печати. Предыдущие печати сохраняют свою стоимость; **Пересчитать стоимость** не меняет износ.
- Оставьте поле пустым или укажите 0, чтобы отключить учёт износа для этого принтера.
- Как и для энергии, карточка архива показывает износ первой печати; каждая повторная печать имеет собственное значение в журнале.
- Износ отображается на карточке архива (значок :material-wrench:), в скрытом столбце **Стоимость износа** журнала печати, плитке краткой статистики, итогах проекта и измеренной стоимости [пакетного заказа](print-queue.md).
- Начисления в разделе [Расчёты](billing.md) по-прежнему включают только филамент. Износ входит в ваши затраты на печать, но Bambuddy не выставляет его к оплате.

### Пересчёт стоимости {#recalculate-costs}

При изменении цены катушки или стоимости филамента по умолчанию существующие архивы сохраняют первоначальную рассчитанную стоимость. Чтобы обновить все архивы по текущим ценам:

1. Нажмите **Пересчитать стоимость** в заголовке панели
2. Каждая запись расхода катушки получает текущую цену катушки: её собственную цену в учёте филамента или [Spoolman](spoolman.md), либо стоимость филамента по умолчанию для встроенной катушки без цены. Запись удалённой катушки сохраняет прежнюю стоимость. Если Spoolman недоступен, записи его катушек сохраняют свою цену, а сообщение укажет их количество.
3. Стоимость каждого архива пересчитывается на их основе как стоимость **одной печати**. Часть граммов, учтённая катушками за все печати архива, оценивается по их средней цене за грамм, а остальное — по стоимости филамента по умолчанию. При отсутствии записей расхода применяется цена из каталога филамента или стоимость по умолчанию.
4. Стоимость каждой печати в журнале изменяется на величину изменения её собственных записей расхода, поэтому статистика тоже учитывает новые цены. Вместо этого последняя завершённая печать архива получает новую стоимость архива, если она ещё имела прежнюю стоимость архива и либо не имеет записей расхода, либо содержит все записи архива.

!!! info "Стоимость повторных печатей"
    Карточка архива показывает стоимость одной печати файла, и повторная печать её не меняет. Каждая печать, включая повторные, имеет собственную запись и стоимость в журнале; статистика суммирует их и отражает общий расход филамента на все печати одного файла.

## :material-lightbulb: Советы {#tips}

!!! tip "Еженедельный обзор"
    Проверяйте панель каждую неделю, чтобы вовремя замечать тенденции и проблемы.

!!! tip "Анализ по принтеру"
    Используйте фильтр принтера, чтобы выявить проблемы надёжности отдельных машин.

!!! tip "Учёт затрат"
    Настройте цены филамента, чтобы понимать фактические расходы на печать.

!!! tip "Ежемесячный экспорт"
    Экспортируйте данные раз в месяц для учёта и долгосрочного анализа.

!!! tip "Точность времени"
    Следите за точностью оценок времени, чтобы лучше планировать печать.

!!! tip "Закономерности в календаре"
    Календарь активности показывает ваши привычки печати и помогает планировать работу.
