# Места хранения {#storage-locations}

Используйте **Места хранения**, чтобы называть физические места, где находятся катушки вне AMS: полки, ящики, сухие боксы и т. п. Bambuddy ведёт каталог, которым можно управлять через **Филамент → Места хранения**, выбирать место в форме катушки и фильтровать по нему список филамента.

[:material-arrow-right: Обзор учёта филамента](inventory.md)

---

## :material-map-marker: Расположение и место хранения {#location-vs-storage-location}

В Bambuddy используются два разных понятия:

| Название в интерфейсе | Значение |
|----------|---------|
| **Расположение** (столбец таблицы филамента) | Слот AMS или назначение принтеру (например, `H2D-1 B4`) |
| **Место хранения** | Физическая полка, ящик или сухой бокс, где хранится катушка вне AMS |
| **Страница мест хранения** | Каталог именованных мест хранения с количеством катушек |

Страница **Места хранения** предназначена только для физических мест. Назначение слоту AMS или принтеру не меняется — см. [Назначение слота AMS](inventory.md#ams-slot-assignment) на странице учёта филамента.

## :material-view-list: Каталог мест хранения {#locations-catalog}

Откройте **Филамент → Места хранения**, чтобы просматривать, добавлять, переименовывать и удалять места.

![Страница мест хранения](../assets/inventory-locations-page.png){ .screenshot }

В каждой строке указаны:

- **Название** — выбранное вами имя (например, `4l drybox`, `Locker`, `Shelf A`)
- **Катушки** — количество активных катушек в этом месте
- **Действия** — изменение или удаление места

Чтобы создать запись, нажмите **+ Добавить место**. Названия должны быть уникальными без учёта регистра: `Shelf A` и `shelf a` считаются одним названием.

!!! tip "Фильтрация филамента по месту"
    Нажмите **название** места в таблице, чтобы перейти на страницу филамента с фильтром по этому месту хранения.

---

## :material-filter: Фильтр по месту хранения {#filter-by-storage-location}

На странице **Филамент** используйте фильтр **Место хранения**, чтобы показать катушки с одной полки или из одного ящика.

![Филамент с фильтром по месту хранения](../assets/inventory-location-filter.png){ .screenshot }

В списке отображаются все места из каталога и вариант **Место не указано** для катушек без назначения. Фильтр скрыт, пока хотя бы одной катушке не назначено место хранения, чтобы не загромождать интерфейс новой установки.

Можно также перейти по прямой ссылке, например `/inventory?location_id=2`.

---

## :material-pencil: Назначение места хранения {#assign-a-storage-location}

При добавлении или изменении катушки откройте раздел **Дополнительно** и выберите **Место хранения** из списка. Можно также ввести новое название и нажать **Добавить**, чтобы создать место, не выходя из формы.

![Редактирование катушки — выбор места хранения](../assets/inventory-edit-storage-location.png){ .screenshot }

!!! info "Этикетки и QR-коды"
    Название места хранения можно печатать на этикетке любого шаблона (см. [Печатные этикетки](inventory.md#printable-labels)). По умолчанию оно включено; чтобы исключить его, снимите отметку **Место хранения** при выборе содержимого этикетки.

---

## :material-database-sync: Переход от текстового поля места хранения {#upgrade-from-free-text-locations}

Если до появления этой функции вы уже использовали свободное текстовое поле **Место хранения**, при обновлении Bambuddy автоматически импортирует его значения в каталог. Повторяющиеся названия объединяются без учёта регистра, а существующие катушки связываются с соответствующими записями каталога.

Повторно вводить места после обновления не нужно.

---

## :material-database-sync-outline: Интеграция со Spoolman {#spoolman-integration}

Когда включён [Spoolman](spoolman.md), Bambuddy продолжает вести локальный каталог мест хранения в собственном интерфейсе учёта филамента:

- При назначении места его **название** записывается в поле `location` соответствующей катушки в Spoolman
- При просмотре списка мест отдельные названия могут синхронизироваться из Spoolman в каталог
- При переименовании места в Bambuddy соответствующее значение массово меняется у катушек в Spoolman

!!! note "Два поля расположения в Spoolman"
    Поле `location` в Spoolman содержит название **физического места хранения**, заданное в Bambuddy. Строки слотов AMS (например, `Workshop X1C - AMS A Slot 1`) управляются отдельно через синхронизацию AMS — см. [Интеграция со Spoolman](spoolman.md#automatic-features).

## :material-gauge: Датчики Home Assistant {#home-assistant-sensors}

Привяжите к месту датчик температуры, влажности или заряда батареи Home Assistant, чтобы видеть текущие показания на карточке филамента и в таблице. Доступны настраиваемые пороги оповещений и уведомления. Подробности см. в разделе [Датчики → Датчики мест хранения](sensors.md#storage-location-sensors).

---

## :material-lightbulb: Советы {#tips}

!!! tip "Начните с реальных полок"
    Добавьте места, которыми действительно пользуетесь, — `Drybox 1`, `Office shelf`, `Garage drawer` — и назначайте им катушки при внесении в учёт.

!!! tip "Быстрый поиск катушек"
    Перед печатью используйте фильтр по месту, чтобы увидеть всё содержимое сухого бокса или ящика.

!!! tip "Короткие названия"
    Короткие названия лучше помещаются на печатных этикетках и кнопках фильтра.
