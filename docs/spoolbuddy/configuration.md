# Настройка {#configuration}

На этой странице описаны рабочие настройки демона и киоска SpoolBuddy.

---

## :material-key: Подключение к серверу {#backend-connection}

Демон SpoolBuddy читает настройки подключения из файла:

- `/opt/bambuddy/spoolbuddy/.env` (путь установки по умолчанию)

Минимальная конфигурация:

```bash
SPOOLBUDDY_BACKEND_URL=http://192.168.1.100:8000
SPOOLBUDDY_API_KEY=bb_xxx
```

Необязательные параметры:

```bash
SPOOLBUDDY_DEVICE_ID=sb-yourfixedid
SPOOLBUDDY_HOSTNAME=spoolbuddy-pi
```

После изменений выполните:

```bash
sudo systemctl restart spoolbuddy
```

!!! tip "Где получить ключ API"
    Создайте ключ в **Bambuddy → Настройки → Ключи API**. При создании выберите **полные разрешения**.

---

## :material-monitor-dashboard: Доступ к киоску и аутентификация {#kiosk-access-and-auth}

Киоск доступен по адресу:

- `/spoolbuddy`

URL киоска, созданный установщиком, обычно содержит токен:

- `/spoolbuddy?token=bb_xxx`

При первой загрузке Bambuddy сохраняет токен и удаляет его из видимого URL.

---

## :material-nfc: Работа NFC {#nfc-behavior}

SpoolBuddy поддерживает:

- **RFID-метки Bambu** (MIFARE Classic; чтение метаданных лотка и материала)
- **Метки NTAG** (`NTAG213/215/216`) для записи пользовательских данных

### Запись меток {#tag-writing}

Запись меток доступна в интерфейсе киоска по адресу:

- `/spoolbuddy/write-tag`

Текущий формат записи:

- Данные NDEF, совместимые с OpenTag3D (`application/opentag3d`)

---

## :material-scale: Весы и калибровка {#scale-and-calibration}

Настройки весов находятся в разделе **Настройки** киоска:

- Вкладка **Весы** — установка нуля и калибровка
- Вкладка **Экран** — яркость и время до отключения экрана

Порядок калибровки:

1. Уберите весь вес и выполните **Установить ноль / Тарировать**
2. Положите груз известной массы
3. Запустите **Калибровать**

Демон получает и применяет калибровку через периодический сигнал состояния, после чего данные сохраняются через Bambuddy.

!!! tip "Используйте для калибровки груз известной массы 1–2 кг"
    Для датчика на 5 кг более тяжёлый эталонный груз (около 20–40% полного диапазона) обеспечивает более стабильную калибровку.

## :material-sync: Синхронизация устройства {#device-sync-model}

Демон:

- регистрирует возможности устройства (NFC, весы, подсветка)
- периодически отправляет сигнал состояния
- передаёт результаты сканирования меток и показания весов
- получает ожидающие команды (например, `tare`, `write_tag`)

Если сигналы состояния прекращаются, по истечении тайм-аута устройство помечается как отключённое.

### Особенности работы с AMS {#ams-behavior-clarification}

SpoolBuddy **не переключает катушки физически**.  
Он настраивает в слотах AMS информацию о филаменте и K-профилях и работает совместно с функциями AMS и учёта филамента Bambuddy.

## :material-cog: Управление устройствами из Bambuddy {#managing-devices-from-bambuddy}

Каждый зарегистрированный киоск SpoolBuddy отображается в **Bambuddy → Настройки → SpoolBuddy**.

Вкладка показывает:

- **Состояние подключения** — индикатор онлайн/офлайн, время последнего обнаружения и время работы демона.
- **Сведения о системе** — имя хоста, ID устройства, IP-адрес, версию прошивки, температуру процессора, использование памяти и диска, ОС, ядро, архитектуру и время работы системы.
- **Состояние оборудования** — состояние NFC-считывателя и весов по последнему сигналу.
- **Счётчик устройств** — заголовок вкладки показывает количество зарегистрированных устройств и то, подключено ли хотя бы одно из них (зелёная точка) или все отключены (серая точка).

### Отмена регистрации устройства {#unregistering-a-device}

Нажмите **Удалить регистрацию** на карточке устройства, чтобы удалить его из базы данных. Перед удалением появится запрос подтверждения.

Устройство, которое всё ещё подключено, **зарегистрируется снова** при следующем сигнале состояния. Поэтому отмена регистрации активного киоска обратима: он появится вновь через несколько секунд. Чтобы удалить SpoolBuddy окончательно, сначала остановите его демон или выключите Pi, а затем отмените регистрацию.

### Удаление дубликата после сбоя {#crash-duplicate-cleanup}

Если демон SpoolBuddy аварийно завершился при первой регистрации или потерял постоянный `device_id`, он может зарегистрироваться повторно с новым ID. Интерфейс киоска использует первое зарегистрированное устройство, поэтому дубликат не используется, но остаётся в списке.

Когда зарегистрировано более одного устройства, вкладка SpoolBuddy показывает жёлтое предупреждение. Отмените регистрацию устаревшего дубликата; оставшееся подключённое устройство продолжит работать как обычно.

---

## :material-update: Обновление {#updating}

Для обычного обновления Pi полная переустановка, как правило, не требуется.

Типичный порядок действий:

```bash
git pull
sudo systemctl restart spoolbuddy
```

Если локальная копия устарела, сначала обновите её, затем выполните ту же команду перезапуска.

## :material-alert: Устранение неполадок {#troubleshooting}

### Устройство остаётся отключённым {#device-stays-offline}

- Проверьте `SPOOLBUDDY_BACKEND_URL` и `SPOOLBUDDY_API_KEY`.
- Проверьте журналы службы:

```bash
sudo journalctl -u spoolbuddy -f
```

### Зарегистрированы два устройства SpoolBuddy {#two-spoolbuddy-devices-registered}

После сбоя демона киоск может зарегистрироваться повторно, оставив устаревший дубликат в списке устройств Bambuddy. Интерфейс киоска использует только первое зарегистрированное устройство, поэтому дубликат не мешает работе, но его легко не заметить.

Решение: откройте **Настройки → SpoolBuddy** в Bambuddy. Если зарегистрировано более одного устройства, появится жёлтое предупреждение. Нажмите **Удалить регистрацию** у устаревшей записи и подтвердите действие. Оставшееся подключённое устройство продолжит работать без перерыва.

### NFC не обнаружен {#nfc-not-detected}

- Проверьте подключение PN5180 и включение SPI
- Проверьте `dtoverlay=spi0-0cs`.
- Выполните:

```bash
sudo /opt/bambuddy/spoolbuddy/venv/bin/python /opt/bambuddy/spoolbuddy/scripts/pn5180_diag.py
```

### Весы не показывают значения {#scale-shows-no-readings}

- Убедитесь, что NAU7802 виден на шине I2C 1:

```bash
sudo i2cdetect -y 1
```

- Выполните:

```bash
sudo /opt/bambuddy/spoolbuddy/venv/bin/python /opt/bambuddy/spoolbuddy/scripts/scale_diag.py
```

### Калибровка весов нестабильна {#scale-calibration-is-inconsistent}

- Убедитесь, что RFID-считыватель не создаёт механических или электрических помех платформе весов.
- При необходимости переместите RFID-считыватель подальше от зоны взвешивания и повторите калибровку.

### Регуляторы яркости не работают {#brightness-controls-do-nothing}

- Яркость HDMI-дисплеев уменьшается с помощью CSS фронтенда
- Для физического управления подсветкой необходимы устройство подсветки DSI и разрешения группы `video`

### Экран гаснет при подключении сенсора {#display-goes-blank-when-connecting-touch}

- Это может указывать на проблемы питания или заземления дисплея (например, поведение, похожее на петлю заземления).
- Проверьте работу с другим Pi или источником питания, а также кабели и ориентацию адаптера.
