# Необходимые материалы {#materials-required}

На этой странице приведён практический список компонентов для актуальной интегрированной сборки SpoolBuddy.

---

## :material-format-list-bulleted: Основные компоненты {#core-bom}

| Категория | Компонент | Количество |
|----------|------|-----|
| Вычислительное устройство | Raspberry Pi 4B (рекомендуется от 4 ГБ; 2 ГБ для режима только SpoolBuddy) или Raspberry Pi 5 | 1 |
| Дисплей | Сенсорный IPS-дисплей LAFVIN 7 дюймов, HDMI LCD 1024x600 | 1 |
| NFC | NFC-считыватель PN5180 | 1 |
| АЦП весов | SparkFun Qwiic NAU7802 | 1 |
| Весы | Одноточечный весовой датчик на 5 кг | 1 |
| Метки | Наклейки или карты NTAG213/215/216 | По необходимости |
| Питание | Оригинальный или качественный блок питания Pi | 1 |
| Подключение питания | Угловой разъём USB-C на 90° | 1 |
| Накопитель | Качественная карта microSD | 1 |

Примечание: комплект дисплея включает адаптеры для Raspberry Pi (угловые адаптеры HDMI/micro USB), что упрощает монтаж и подключение.

## :material-soldering-iron: Принадлежности для подключения и сборки {#wiring-and-build-supplies}

| Предмет | Назначение |
|------|-----|
| Паяльник | Необходим для подключения проводов и модулей. |
| Флюс (необязательно) | Улучшает растекание припоя и качество соединений. |
| Медная стружка / очиститель жала | Поддерживает жало паяльника чистым для надёжной пайки. |
| Изопропиловый спирт (необязательно) | Удаляет липкие остатки флюса после пайки. |
| Термоусадочная трубка | Удерживает провода вместе, изолирует и разгружает соединения от натяжения. |
| Припой с флюсом внутри | Рекомендуется для более простой и аккуратной пайки. |
| Вытяжка для дыма при пайке (необязательно) | Отводит дым от зоны дыхания. |
